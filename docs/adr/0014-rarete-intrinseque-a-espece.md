# Rareté intrinsèque à l'espèce

La rareté est une propriété intrinsèque de l'espèce (commune, peu commune, rare), pas un paramètre du tier de croissance. Le prix des graines, le prix de vente au marché et le quota quotidien sont tous dérivés de l'espèce. La brillante est un tier posé par-dessus (une variante rare d'une espèce existante), jamais une rareté d'espèce distincte. Ce choix simplifie le modèle : une espèce = un profil économique cohérent, et la brillante est une couche cosmétique/de collection par-dessus, pas un calibrage séparé.
