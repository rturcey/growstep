# Sources provisoires des sprites végétaux hérités

Les 23 sprites hérités de plantes et d'arbres ont perdu leurs sources de travail. Pour les intégrer sans redessiner les espèces, nous acceptons provisoirement un fichier ORA aplati par sprite, identifié comme tel, puis normalisons chaque master au format 4× et en dérivons les exports 2× et 3×. Cette source permet de respecter le pipeline et de corriger l'ancrage, mais ne reconstitue pas les couches d'origine : toute retouche profonde demandera de recréer une vraie source modifiable.
