# Ne pas retirer les récompenses déjà accordées

Les pas d'une journée peuvent être ajoutés ou corrigés après coup. L'application crédite les doses d'eau et d'engrais manquées si le total augmente, mais ne reprend jamais une récompense déjà accordée si le total baisse. Cette règle privilégie la promesse d'un jardin sans malus ; elle impose de mémoriser les récompenses déjà créditées pour éviter les doublons lorsque les pas sont relus.
