# Ne pas retirer les récompenses déjà accordées

Les pas d'une journée peuvent être ajoutés ou corrigés après coup. L'application crédite les récompenses manquées si le total augmente, mais ne reprend jamais une récompense ou une transformation du jardin déjà accordée si le total baisse. Cette règle privilégie la promesse d'un jardin sans malus ; elle impose de mémoriser ce qui a déjà été crédité pour éviter les doublons lorsque les pas sont relus.
